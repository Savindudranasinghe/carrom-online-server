# Carrom Online V6 — Production-ready deployment package

Includes:
- server-authoritative multiplayer foundation
- deterministic physics
- 1v1 / 2v2 rooms
- Docker deployment
- Render deployment manifest
- Fly.io deployment manifest
- health check
- environment-driven port
- basic connection cap

This package still requires deployment to a cloud host and configuration of the resulting WSS URL in the Android/web client. A cloud account and domain are not automatically created by this package.
